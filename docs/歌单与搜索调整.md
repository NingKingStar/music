# 歌单与搜索调整

本次修改基于 `77790dff`（v0.9.6），按用户确认的独立分类规则实现。

## 页面与交互

- 底栏为“探索 / 歌单 / 我的”。探索页顶部固定搜索入口，展开和紧凑底栏均移除独立搜索按钮。
- “歌单”首页显示“我喜欢”“已下载”和自建歌单，支持新建、重命名和删除自建歌单。
- 心形仅控制“我喜欢”，不触发下载、不修改自建歌单。本地和 WebDAV 歌曲不再自动算作喜欢，也可以取消喜欢。
- 歌曲的独立加号打开“添加到歌单”，仅列出自建歌单，支持多选与现场新建。已经加入的歌单显示“已添加”，不会因再次添加而重复，也不从这里移除。
- 自建歌单内的“从当前歌单移除”只删除该歌单关联，不修改“我喜欢”、其他歌单或实际文件。
- “已下载”由成功保存且有实际目标位置的完成任务收录。失败、等待、暂停和上传中的任务均不收录；从下载列表进入下载管理可继续管理任务。
- “我的 → 本地与云端音乐”保留原曲库的歌曲、专辑、艺术家与扫描功能。

## 数据与兼容

- 喜欢沿用 `favorite_songs_v1`，原有显式手动选择仍然有效；不会把整份本地曲库批量变成“喜欢”。
- 自建歌单存于 `user_playlists_v1`，保存独立的 ID、名称和曲目快照。成员操作限定在指定自建歌单 ID 内。
- 已下载存于 `downloaded_songs_v1`，与 `download_queue_v1` 分开。旧版尚存的完成任务即时可见，并在下一次队列变更时原子保存迁移；清理任务时先保留原有完成记录。
- 旧版本已经被清理的下载任务没有历史依据，本次不会扫描文件并猜测其下载来源。
- 曲目快照增加可兼容默认值的 `sourceType`，使本地和 WebDAV 歌单在重启后保留播放来源。
- 在线收藏或自建歌单已有同曲下载时，播放优先使用下载文件，但不改变任何集合的成员关系。
- 设备下载目录不属于扫描音源，其文件引用在进入播放前登记到曲库，供桌面和播放服务按 ID 查询。
- 不添加远程同步范围；新集合目前保存在各设备的应用数据中。已下载记录不持续扫描外部文件删除，实际文件被移走时仍由播放器报告读取错误。

## 验收场景

1. 打开探索，顶部进入搜索；返回回到探索。底栏展开、紧凑模式都没有右侧搜索按钮。
2. 搜索一首歌，点击心形后只出现在“我喜欢”；再次点击心形后移除，不影响自建歌单。
3. 新建甲、乙两个歌单，用加号同时加入同一首歌；在甲歌单移除后，乙歌单和喜欢状态保留。
4. 重复添加同一首歌，歌单不产生重复项；取消选择器时不修改已有歌单。
5. 下载失败或暂停时“已下载”没有该歌曲；成功保存后自动出现。
6. 清理下载任务的完成记录，已下载列表和实际文件仍保留；加号选择器没有“已下载”或“我喜欢”选项。
7. 在已下载歌曲上点击喜欢或添加到自建歌单，相应分类单独增加，不更改已下载记录。
8. 重启后检查喜欢、自建歌单和已下载记录；从本地、云端及下载列表播放，核对来源与歌词。
9. 从自建歌单删除歌曲或删除整个歌单，实际音乐文件、其他歌单和喜欢不变。
10. 在“我的”中进入本地与云端音乐，检查原有歌曲、专辑、艺术家与扫描入口。

## 回归测试

### 点击反馈与下载管理（版本码 100099）

- 搜索结果卡片开启原生轻微下沉和按压高亮；通用歌曲行增加淡色过渡，不新增点击音效或振动。
- 在线歌曲与播放器菜单的“下载歌曲”直接入队并开始；再次点击待下载、暂停或失败的同一任务时复用原记录并继续，已在运行的不重复启动。内部仅排队接口保留，避免改变批量调度逻辑。
- 下载管理顶部独立“下载中 / 已完成”分页，未完成任务细分为进行中、等待、暂停和需要处理。任务卡片移除固定缩进，进度横贯卡片，状态、百分比、大小分层显示；音质和保存位置收进详情。
- 下载、保存、上传分别使用各自真实字节进度；总大小未知时明确提示已传输量，准备地址、整理信息、上传核验采用不定进度，不冒充完成。
- 已完成分页读取持久已下载集合，可点击歌曲播放、查看保存位置；清理任务记录后完成音乐仍保留。
- 本轮新增 8 项进度展示测试和 2 项真实下载管理集成测试；搜索模块 22 项、导航壳模块 76 项测试通过。具体手机上的动画、排版和下载行为仍待实机验收。
- 图标仅提供参考，第一组已被用户否决。第二组简约参考未确认，本版保留原图标。

### 输入自动搜索与整行播放（版本码 100098）

- 搜索结果使用卡片自身的点击入口，点击封面、标题或歌曲行空白区域即可播放；移除独立播放图标。喜欢、添加歌单和下载按钮仍独立操作。
- 搜索框输入暂停 350 毫秒后自动查询，单个汉字或字母也可触发。回车立即搜索并取消待执行的自动查询，避免重复请求。
- 输入变化立即取消旧查询并作废旧响应和分页；清空输入撤销待执行查询并清空结果。切换分类、下拉刷新均使用当前输入。
- `OnlineSearchInteractionTest` 新增 8 项回归测试；本轮 `:feature:sources:jvmTest` 共 22 项通过，覆盖延迟合并输入、手动提交去重、清空与旧请求隔离、分类切换、分页隔离及播放队列。
- 实机还需确认：点击歌曲标题与空白区域可播放，右侧操作不误播；快速改词和清空后显示正确；覆盖安装保留歌单。
