# Muses 0.9.11

本版优化外语歌词、读音与歌词页操作，沿用正式版签名，可直接覆盖更新 0.9.10，无需卸载。

## 更新内容

- 优化外语译文筛选与补全，改善歌词自然折行；日语罗马音、韩语罗马字读音独立补全和缓存。
- 翻译与音译互斥：开启一项自动关闭另一项，也可以都关闭只看原文；选择即时保存，重启保留。
- 可靠的逐词时间轴才显示对应词上方注音；否则显示整句读音，避免按字数硬拆。过滤与原文重复的无效读音，并修复部分逐字歌词首字丢失及错位。
- 歌词页保留「译、音、词」与播放/暂停；缺少译文或音译时按钮禁用，不再误打开设置。
- 重做歌词设置沉浸弹层，使用播放器封面背景；提供当前句预览、字号、句间距和逐字高亮，取消多余的「完成」。支持手柄下滑、遮罩和返回关闭。
- 统一按钮居中、圆角按压及缩放反馈；歌词界面不显示第三方平台来源文字。
- 读音与译文分别检查、共享请求并限制并发；有效缓存优先显示，失败短退避，刷新失败保留已有内容，避免不同版本歌词串用。

## 下载与安装

下载附件 muses-v0.9.11.apk。最低支持 Android 10，包名 com.muses.player，版本码 100147，使用项目原签名。已有同签名正式版可直接覆盖更新。

本次提供安卓正式安装包及 SHA256SUMS.txt 校验文件。共存测试版保留独立。

## 验证与说明

- 相关自动化测试 590 项通过，失败、错误、跳过均为 0。
- 11 首日语、韩语歌曲的既有真实响应重放，验证读音解析及跨加载器磁盘缓存一致性；不等同于在线成功率或逐首实机播放。
- 没有可靠读音资源的歌曲仍可能暂无音译，不以中文谐音或机器猜测冒充平台注音。
