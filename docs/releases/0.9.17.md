# Muses 0.9.17

- “我的”中增加独立“检查更新”入口，设置行不再附带更新提示。
- 探索首页与全部榜单使用首首歌曲封面，替换文字色块海报；标题保持静态展示。
- 封面复用首曲缓存，按需加载并限制并发，缺图使用占位。

## 从 GitHub 0.9.14 升级还包含

- 国内 HTTPS 更新通道，清单和安装包均可从国内站点获取，GitHub 作为备用。
- 独立更新详情页、下载与校验状态、失败重试及安装操作。
- 歌手主页显示真实头像、别名、简介与歌曲列表，资料与歌曲独立加载和缓存。

## 安装与核验

- Android 10 及以上，包名及原签名不变，支持覆盖安装。
- 0.9.16 用户可在客户端检查更新；更早版本可从本 Release 或 https://up.raink.cloud/ 下载覆盖安装一次。
- 194 项本轮相关回归通过，正式包经过签名、包名、版本及 16K ZIP 对齐检查。
- 手机由用户自行更新，本次未提前安装到设备。
