# Muses 0.9.9

本版优化歌单与播放模式的界面和操作反馈，沿用正式版签名，可直接覆盖更新 0.9.8，无需卸载。

## 更新内容

- 歌单页统一新建与导入入口，操作菜单融入歌单行，并显示真实歌曲封面。
- 歌单详情重新组织封面、数量和播放、下载操作，保留搜索、收藏与歌曲菜单。
- 新建、重命名、导入和添加到歌单使用底部表单；添加到歌单支持搜索和多选，新建操作分步呈现。
- 列表搜索闲置时隐藏“取消”，输入后显示清空与退出；清空保留输入状态，取消恢复完整列表并收起键盘。
- 播放模式按钮单击直接切换、长按展开竖向气泡；每项横向显示图标与名称，仅用高亮表示当前选择。
- 播放模式气泡采用紧凑自适应宽度和柔和灰阶，增加按压、滑块回弹、图标微动与淡入淡出反馈，连续切换时保持展开。

原有音源选择、音质回退、缓存、歌词和下载功能保留。共存测试包的数据独立，不会自动迁入正式版；正式版原有数据继续保留。

## 下载与安装

下载附件 `muses-v0.9.9.apk`。安卓最低版本为 Android 10，包名为 `com.muses.player`，使用项目原签名。

`SHA256SUMS.txt` 提供安装包校验值。首次安装按系统提示授予必要权限；已有正式版直接覆盖更新。
