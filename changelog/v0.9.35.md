# Muses 0.9.35

## 译文补齐：多了「按歌词搜歌」这条兜底

- 现象：歌名是中文译名的外文歌（比如韩语歌）常常补不到译文——因为按歌名搜网易搜不到原曲。
- 新增兜底：标题搜不到候选时，取当前歌词里最长的一行原文，用网易**歌词搜索（type=1006）**找回原曲，再按原来的"跨版本按时间对齐"合并。
- 实测：用韩语歌词行搜索能直接命中正确版本（含时长一致的原版），不受中文译名影响。
- 依然是并发 + 单请求 2 秒封顶 + 失败静默，不影响播放与歌词显示。

## 界面：清掉一批旧文字按钮

- 新增统一胶囊组件 `MusesPill`（50% 圆角、实心块、13sp，与搜索页分类胶囊同一套视觉）。
- 替换掉的旧样式：
  - 搜索历史：「管理 / 完成 / 清空 / 展开全部 / 收起」原本是裸文字按钮；
  - 搜索结果：「排序」原本是文字按钮，改为与分类胶囊同款（选中态实心）；
  - 搜索结果：「更多音源 · N 个 ›」原本是一行蓝色文字链接，改为胶囊。
