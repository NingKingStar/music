# Muses 0.9.26

## 副歌节点：修命中率

- 之前副歌是「另起一次网易搜索」找 id，跟歌词匹配是两套查询，经常搜不到就当作没有。现在**复用歌词匹配时已经确定的那个网易歌曲 id**，同一首歌不再重复碰运气。
- 歌词来自洛雪脚本或内嵌标签时，之前根本不触发副歌计算；现在所有歌词入口都会触发。
- 原生区间拿不到时仍用歌词重复段落兜底。

## 译文 / 音译：用同一个网易 id 补齐

- 实测样本 **Insomnia（辉星）**：网易该版本同时提供 	lyric（中文翻译 630 字）与 omalrc（韩语音译 1745 字），副歌区间 28.5s–80.5s 也在。也就是说这类歌缺的从来不是数据，是我们没去取。
- 新增：当当前歌词**判定需要补全**（外文歌词、译文/读音覆盖不足）时，用同一网易 id 取译文与音译，按行时间合并进现有歌词。
- 只在覆盖不足时触发，不会覆盖掉已有的更高优先级译本。
